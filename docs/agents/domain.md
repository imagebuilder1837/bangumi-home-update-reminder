# Domain docs

## 探索前读取

采用 single-context 布局：

- 根目录 `CONTEXT.md`：领域术语和上下文。
- `docs/adr/`：读取与当前工作相关的决策记录。

文件不存在时静默继续，不主动建议创建；
由 domain-modeling 技能在术语或决策明确后按需创建。

## 术语与决策

输出中的领域概念使用 `CONTEXT.md` 定义的术语，
避免使用词汇表明确排除的同义词。

缺少所需概念时，先判断是否引入了项目不用的语言；
确有缺口则提示交由 domain-modeling 处理。

方案与已有 ADR 冲突时，明确指出对应 ADR 和重新讨论的理由，
不要静默覆盖已有决策。
